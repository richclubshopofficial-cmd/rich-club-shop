RICH CLUB ONLINE SHOP — STARTER PROTOTYPE

Files:
- index.html: responsive storefront and demo admin dashboard

How to run:
1. Extract rich_club_shop.zip.
2. Double-click index.html to open it in Chrome/Edge.
3. Click Admin and enter demo password: richclub-demo.
4. Add/edit products, prices, stock and descriptions. Product/order demo data is saved in that browser's local storage.

Important limitations:
- This is a front-end prototype, not a production e-commerce system.
- No real secure login, central database, server-side stock protection, email/WhatsApp notifications, or payment gateway is configured.
- Data is stored in one browser on one device; it does not sync to customers or other devices.
- Do not use this demo to store real customer information or take real payments.
- To launch a real store, add a backend/database, secure admin authentication, order notifications, privacy/security measures, and a payment provider. A free static host can publish the visual demo, but production admin/order features need a backend (which may have free-tier limits).
